📋 DATA FORMAT NOTICE & REQUIREMENTS (फ़ाइल फ़ॉर्मेट निर्देश)

यदि आप अपनी खुद की डेटा फ़ाइल (CSV या JSON) अपलोड कर रहे हैं, तो सुनिश्चित करें कि आपकी फ़ाइल में नीचे दिए गए Columns / Headers अनिवार्य रूप से मौजूद हों:

Column Header Data Type Required? Example Values Description
city Text Yes Jodhpur, Jaipur, Delhi City where property is located
state Text Yes Rajasthan, Maharashtra State name
purpose Text Yes RENT or BUY Property purpose (Rent or Purchase)
price Number Yes 25000, 8500000 Price in INR (Monthly Rent or Buy Price)
bhk Integer Yes 1, 2, 3, 4 Number of bedrooms
area_sqft Number Yes 1250, 2400 Super built-up area in square feet
property_type Text Optional APARTMENT, VILLA, HOUSE Structural configuration
title Text Optional Luxury 3 BHK Flat Property title or description
